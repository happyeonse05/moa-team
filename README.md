# 모아 (MOA)

청년정책 신청을 돕는 대학 팀 프로젝트의 웹 프로토타입입니다. 원본 화면과 기능을 보존한 정적 HTML 앱이며 외부 라이브러리나 실제 API를 사용하지 않습니다.

## 실행 방법

Python 3가 설치된 환경에서 저장소 폴더로 이동해 로컬 서버를 실행합니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. 별도 패키지 설치나 빌드 과정은 필요하지 않습니다.

## 포함된 기능

- 온빛 하트 전구와 신청 진행 3단계 표시
- 정책 자격 확인과 증빙서류 체크리스트
- 관심 정책 스크랩과 검색
- 서류 보관·재사용과 마감일 캘린더, `.ics` 파일 내보내기
- 예시 정책 추천 및 시연용 커뮤니티 글 등록·삭제
- 모바일·데스크톱 반응형 화면

## 데이터와 사용 범위

화면의 정책·자격·기한·서류 정보는 시연용 예시입니다. 앱 상태는 현재 브라우저의 `localStorage`, 첨부한 시연 파일은 `IndexedDB`에 저장되며 다른 기기나 사용자와 동기화되지 않습니다. 테스트에는 개인정보가 없는 예시 파일만 사용하세요.

실제 정책 데이터/API, 본인 확인·실명 인증, 정부 서류 자동 발급, 캘린더 계정 자동 동기화, 다중 사용자 서버는 연결되어 있지 않습니다. 추천은 예시 서류가 겹치는 정책을 보여주는 임시 규칙입니다.
